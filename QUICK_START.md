## 🚀 Get Started in 5 Minutes

### What You Have
✅ Professional responsive portfolio
✅ Customizable theme system  
✅ Contact form ready
✅ Mobile-friendly design
✅ Production-ready code

### Step 1: Test Locally
1. Open `index.html` in your browser
2. Check that everything looks good
3. Test navigation, buttons, and forms

### Step 2: Customize Your Info
1. Click ⚙️ (Settings icon) in the top-right
2. Update your name, email, and social links
3. Customize colors if desired
4. All changes save automatically

### Step 3: Add Your Images
Replace these files with your own:
- `WIN_20260425_19_19_13_Pro.jpg` - Hero profile photo
- `nigaa.png` - About section photo

**Image Tips:**
- Profile: 300x300px square
- Keep file sizes under 200KB
- Use JPG for photos, PNG for graphics

### Step 4: Update Portfolio Projects
Edit these sections in `index.html`:
1. Find `<!-- PORTFOLIO -->` section
2. Update project titles and descriptions
3. Replace GitHub links with your repositories
4. Customize project categories

### Step 5: Deploy (Choose One)

**🔥 Easiest - Netlify (Recommended)**
1. Go to [netlify.com](https://netlify.com)
2. Drag your folder into the deploy box
3. Your site goes live instantly!
4. You get a free URL like: `your-site.netlify.app`

**Alternative: GitHub Pages**
1. Create GitHub repo
2. Push your files
3. Enable Pages in settings
4. Site lives at: `username.github.io`

**Alternative: Vercel**
1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub project
3. Deploy with one click

## 📧 Enable Email (Optional)

Want contact form to send you emails?

1. Sign up free at [emailjs.com](https://emailjs.com)
2. Add your Gmail as a service
3. Create an email template
4. Copy your **Public Key**, **Service ID**, **Template ID**
5. Paste them in `main.js`:
   ```javascript
   const EMAILJS_PUBLIC_KEY = 'paste_here';
   const EMAILJS_SERVICE_ID = 'paste_here';
   const EMAILJS_TEMPLATE_ID = 'paste_here';
   ```

That's it! Contact form now works.

## ❓ Common Questions

**Q: Can I change the domain later?**
A: Yes! On Netlify/Vercel, go to settings and add custom domain

**Q: What if I want to add more sections?**
A: Copy an existing section, update the content, keep the class names

**Q: Is this free to host?**
A: Yes! Netlify, Vercel, and GitHub Pages are free

**Q: Can I use my own domain?**
A: Yes! Usually costs $10-15/year, then connect to your host

**Q: How do I update the portfolio later?**
A: If on GitHub, push changes. If drag-deploy, just redeploy the updated files

## 🚨 Quick Troubleshooting

**Images not showing?**
- Check file names match exactly
- Verify files are in same folder as HTML

**Colors not applying?**
- Clear browser cache: Ctrl+Shift+R
- Try in incognito/private mode

**Contact form not working?**
- Check EmailJS keys are correct
- Look for errors in browser console (F12)

**Settings not saving?**
- Check localStorage isn't disabled
- Try a different browser
- Clear browser data
